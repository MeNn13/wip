# Устройство пакета

> **Статус и этап.** Руководство по предложению [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D14]] на основании подтверждённого [[Реестр_требований_и_решений#2 Реестр требований|R38]]. П — предлагаемая основа; Р — целевое широкое наполнение. Реализации пока нет; примеры учебные, не готовые файлы для запуска.

Пакет — передаваемый набор метаданных и изменений. Предлагаемый состав задан в [[ГДД/14 Моддинг и пользовательский контент#Пакет и разрешение изменений|требованиях к пакету]]; здесь описан порядок его подготовки.

| Состав | Что записать автору |
|---|---|
| Описание | Стабильный ID мода, имя, автор, версия, назначение |
| Совместимость | Проверенные версии игры, требуемые версии обязательных зависимостей |
| Порядок | Зависимости и ограничения порядка подключения |
| Данные | Добавляемые сущности и явные изменения существующих сущностей |
| Тексты | Ключи и переводы, связанные с сущностями |
| Сопроводительные материалы | Инструкция, журнал изменений, результаты проверок, условия использования и авторство ресурсов |

Это логический состав, не утверждённое дерево файлов. Имя файла описания, расширения, кодировка и правила путей появятся в технической спецификации.

## Идентификаторы и операции

Выберите собственное пространство имён, например условное `lesson.*`, и сохраняйте ID между версиями. Отображаемое название можно переводить, ID сущности от этого не меняется. ID пакета не заменяет ID шаблона или ключ текста.

**Добавить** — объявить новый ID; совпадение с уже существующим ID считается дубликатом. **Изменить** — указать известный ID и конкретные поля. Не копируйте базовую сущность под тем же ID ради изменения: это двусмысленное добавление. Удаление сущностей и его последствия для ссылок пока не специфицированы.

Зависимость на другой мод содержит его ID и допустимые версии. Одного упоминания в описании недостаточно. Порядок должен удовлетворять зависимостям; циклы и несовместимые диапазоны требуют исправления. Произвольная перестановка модов не считается способом устранить конфликт одного поля.

При обновлении увеличьте версию пакета и опишите затронутые ID и поля. Не изменяйте опубликованное содержимое под прежней версией. Пройдите [[Моддинг/07 Совместимость и сохранения|проверку совместимости]] перед передачей обновления.
