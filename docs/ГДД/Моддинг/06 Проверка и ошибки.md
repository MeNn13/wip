# Проверка и ошибки

> **Статус и этап.** Руководство по предложению [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D14]] на основании подтверждённого [[Реестр_требований_и_решений#2 Реестр требований|R38]]. П — предлагаемая основа; Р — целевое широкое наполнение. Реализации пока нет; примеры учебные, не готовые файлы для запуска.

Проверяйте пакет отдельно, затем весь набор с зависимостями, затем новую независимую партию и сохранение. До реализации это перечень будущих испытаний и ручная сверка спецификации; команды валидатора и реальные имена файлов ещё не определены.

Ожидаемая ошибка называет мод и версию, файл, сущность и поле, причину и допустимое значение; конфликт называет оба источника. Пример учебного сообщения: «lesson.width 0.1: файл шаблонов, lesson.infantry, W: получено 0; требуется W>0». «Файл шаблонов» здесь условное обозначение, не реальный путь.

## Каталог ошибок

Обозначения в таблице учебные, не утверждённые коды загрузчика. Все реакции — предложение D14; проверки П перечислены в [[Спецификация_прототипа#Дополнительные проверки моддинга к P11|спецификации]], расширенная проверка контента — V07.

| Ситуация | Ожидаемая диагностика и реакция | Исправление автором |
|---|---|---|
| W=0 в шаблоне | Файл, ID и поле W; недопустимая эталонная ширина; отказ до запуска | Задать положительную W, сверить единицы с ГДД |
| Недопустимое число | Поле, значение и разрешённый диапазон/тип; отказ | Проверить единицы и ограничения поля; не путать долю и проценты |
| Дубликат ID | Оба объявления и файлы; добавление отклонено | Дать новой сущности собственный ID либо явно оформить изменение существующей |
| Неизвестная ссылка | Источник, поле и отсутствующая цель; отказ | Исправить ID или объявить нужную зависимость |
| Два мода меняют одно поле | Оба мода, версии, файлы и целевое поле; конфликт | Согласовать изменения, отключить один пакет или подготовить совместимый вариант; смена порядка сама по себе не исправляет конфликт |
| Нет обязательной зависимости | Описание пакета, поле зависимости, требуемые ID и версии; отказ подключения | Получить совместимую версию зависимости и проверить её собственные зависимости |
| Цикл или неверный порядок | Цепочка модов и ограничения порядка; отказ | Устранить цикл, согласовать порядок с зависимостями |
| Неподдерживаемая версия игры | Описание пакета, заявленная совместимость и текущий билд; отказ | Использовать проверенную сборку либо обновить и заново проверить пакет |
| Несовместимое сохранение | Файл сохранения, поле версии/состава модов, ожидаемый и найденный набор; загрузка блокируется | Восстановить исходную сборку и набор либо начать новую партию; миграция не обещана |
| Потерянный ключ текста | Файл и поле ключа, отсутствующий перевод; ошибка проверки полноты | Восстановить ключ и переводы; политику подстановки уточнить в технической спецификации |

После исправления повторите проверку **всего** набора. Не проверяйте только исправленный файл: ссылка или конфликт могут находиться в другом пакете.

## Что записывать о проверке

Для будущего отчёта укажите сборку, точные пакеты и содержимое, порядок, фикстуру, действия, ожидаемый и фактический результат, приложите сообщение/журнал. При отказе предыдущий мир и исходное сохранение должны остаться целыми. Повтор после сохранения описан в [[Моддинг/07 Совместимость и сохранения|совместимости]].

Документальная проверка существования ссылок и арифметики примера не доказывает работу валидатора, загрузчика или игры. Игровые P10/P11/V07 пока не выполнены.
