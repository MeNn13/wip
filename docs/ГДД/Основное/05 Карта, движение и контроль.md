# Карта, движение и контроль

[[ГДД|← Главная страница ГДД]]

> **Статус правил.** Алгоритмы, формулы, коэффициенты и ограничения являются предложениями, кроме явно подтверждённых положений. Перенос документации не означает утверждения решений. Статусы требований и решений — в [[Реестр_требований_и_решений#1 Правила работы с требованиями|реестре]].

**Цель и действия.** Дать игроку свободу манёвра без административных клеток ([[Реестр_требований_и_решений#2 Реестр требований|R11–R15]]). Игрок выбирает маршрут и режим движения, ставит объект в разрешённой точке, видит фактический и прогнозируемый контроль.

**Входные данные.** Геометрия суши, местность с подтипами, переправы, пути, границы доступа, координаты дивизий, их развёрнутые интервалы и объекты с координатами. Расстояния измеряются по поверхности; для прототипа применяется плоский театр в километрах. Выбор представления Unity и источника геоданных относится к отдельному техническому решению [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D15]].

**Предлагаемые правила контроля [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D05]].** В прототипе дивизия на фронте представлена отрезком развёртывания и опорной точкой в его середине. При поступательном движении в одном направлении она занимает полосу, заметённую отрезком; ~~свободно движущаяся дивизия имеет полосу шириной 2 км~~. *Поворот делится на прямые шаги, ограниченные путём; захват не перескакивает через непроходимость. Не занятые войсками промежутки сохраняют прежний контроль. Никакое замыкание контура не перекрашивает его внутренность автоматически.*

Вражеские развёрнутые отрезки блокируют продвижение пересекающей их полосы. ~~Свободные дивизии контактируют при сближении опорных точек до 2 км~~. Движение прекращается в момент первого контакта, а не после прохождения через противника. Если встречные заявки на новую землю пересекаются в одном шаге, общая область сохраняет прежний контроль до разрешения контакта; бесспорные части полос применяются независимо от порядка обновления сторон. В прототипе разбиение движения ограничивается 1 км за подшаг, чтобы обнаружить пересечение. ==🟡Точность геометрии — 10 м==; погрешность не должна открывать маршрут через закрытый коридор.

Граница контроля и нарисованный фронт — разные сущности. План отражает положение назначенных частей, но его изгиб не захватывает землю. В пустом тылу противник должен физически продвигаться, чтобы занять дорогу или город. Дивизия в окружении сохраняет контролируемый карман, пока его не займут; карман может состоять из нескольких административных регионов.

Объект переходит под фактический контроль, когда его координата попала в бесспорно занятую область и нет вражеского контакта в радиусе 1 км. До этого объект спорный и не отгружает грузы. Производство захваченного объекта заблокировано на ==🟡24 часа== и до выделения оккупационного обеспечения; в прототипе обеспечение считается доступным, задержка сохраняется. Промышленность региона суммируется по отдельным объектам: захват 50% площади не гарантирует 50% заводов. Это раскрытие ответа 3.8 через фактическое положение объектов; срок 24 часа предложен.

**Движение [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D06]].** ==🟠`distance = v0 × terrainSpeed × mode × fuelMove × dt`. Для пехоты `v0=3 км/ч`, для моторизованной части `6 км/ч`; по дороге `mode=4`, вне дороги `1`, по железной дороге `8`. Последние два множителя дороги и ЖД взяты из концепта как ориентиры, а не проверенные скорости. Рельеф для прототипа:==

| Местность | Скорость пехоты и моточасти | Атака | Защита | Допуск моточасти |
| --------- | --------------------------- | ----- | ------ | ---------------- |
| ==🟠Равнина==   | ==🟠1 / 1==                       | ==🟠1==     | ==🟠1==      | ==🟠Да==               |
| ==🟠Лес==       | ==🟠0,6 / 0,4==                   | ==🟠0,8==   | ==🟠1,2==    | ==🟠Да==               |
| ==🟠Болото==    | ==🟠0,4 / 0,2==                   | ==🟠0,6==   | ==🟠1,1==    | ==🟠Да==               |
| ==🟠Горы==      | ==🟠0,3 / 0==                     | ==🟠0,5==   | ==🟠1,5==    | ==🟠Нет==              |

Дорога меняет режим скорости, но не отменяет запрет типа местности. Скорость применяется по местности опорной точки; пересечение границы местности делит движение на интервалы. Контактный отрезок для боя разделяется на границах местности, затем очки дивизии распределяются между полученными отрезками по их длине до применения местного множителя. (==🟢помимо мостов будет возможность установки перевправ без боя как временный мост==, а ==🔵также другие варианты при наличии противника на том берегу (провести ресерч - как штурмовали реки во ВМВ))==; мост блокируется вместе с соответствующим ребром. Горные подтипы, броды и сезонное замерзание вводятся позже по отдельным данным, без заявления, что любой реальный хребет полностью непроходим.

Походный режим (==🔵марш бросок==) доступен ==🟡только по дружественной суше==, ==🟢также по вражеской территории можно продвигаться в глубь по дорогам с увеличенной скоростью (условно организация меньше на 20 единиц из 10, а скорость выше, но меньше такому же по дружественной территории==). На дороге организация не выше 20, при перевозке по ЖД не выше 5 из 100; при выходе в обычное движение восстанавливается со временем. При угрозе в пределах 5 км поход прекращается, дивизия развёртывается ==🟡1 час==, сохраняя низкую организацию. Железнодорожная посадка и выгрузка — только в узлах, ==🟡по часу каждая==; ==🟡решение предварительное, поскольку ответ 9.4 условный==. Дивизионный эшелон занимает одну транспортную единицу и слот ребра наравне с грузом. Игрок не может перевезти часть через занятую врагом станцию.

**Результат и интерфейс.** Маршрут с временем прибытия, слоями проходимости и контроля; для региона отдельно показываются доля площади и список доступных предприятий. Объект имеет состояния свой, спорный, оккупирован и восстанавливается. Непроходимый приказ отклоняется с указанием первого препятствия.

**Исключения и проверка.** Нет маршрута — часть остаётся на месте; смена контроля прерывает движение на безопасной позиции перед препятствием. ==🟣Планирование не открывает скрытого противника==: предупреждение даётся по известным причинам, новая угроза обнаруживается при контакте. Параметры: скорость, радиусы, точность, сроки развёртывания и оккупации. Проверки [[Спецификация_прототипа#4 Сценарии приёмки ядра|P01]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P03]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P05]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P09]].
