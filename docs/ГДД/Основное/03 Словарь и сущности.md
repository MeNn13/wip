# Словарь и сущности

[[ГДД|← Главная страница ГДД]]

> **Статус правил.** Алгоритмы, формулы, коэффициенты и ограничения являются предложениями, кроме явно подтверждённых положений. Перенос документации не означает утверждения решений. Статусы требований и решений — в [[Реестр_требований_и_решений#1 Правила работы с требованиями|реестре]].

| Термин | Игровое значение |
|---|---|
| Административный регион | Область управления населением, строительством и экономикой; не клетка перемещения |
| Владелец | Государство с юридической принадлежностью территории по сценарию или договору |
| Контролирующая сторона | Сторона, фактически удерживающая точку суши; может отличаться от владельца |
| Территория контроля | Геометрическая область фактического контроля; регион может содержать несколько таких областей |
| Граница контроля | Граница областей противоборствующих сторон; включает незанятые промежутки |
| Фронт | Созданный игроком план размещения и управления на полилинии с длиной в километрах |
| Линия обороны | Тот же план в тылу; при приближении вражеского контроля активируется его оборонительная роль |
| Участок | Интервал длины вдоль фронта, закреплённый за конкретной группой или дивизией |
| Дивизия | Минимальная управляемая единица с физическим положением, шаблоном и запасами |
| Приказ | Намерение с целью, исполнителями, параметрами, состоянием и причиной остановки |
| Узел снабжения | Город или построенный хаб со складом и ограниченной обработкой грузов |
| Партия груза | Идентифицируемый объём конкретного ресурса с источником, получателем и транспортом |
| Резерв | Дивизия вне занятого участка; перемещается к месту ввода физически |

Армия и группа армий — уровни выбора и наследования настроек; дивизия одновременно входит только в одну армию и имеет один текущий приказ. Батальоны задают состав шаблона и визуализацию, но не получают отдельных приказов ([[Реестр_требований_и_решений#2 Реестр требований|R16–R18]]).
