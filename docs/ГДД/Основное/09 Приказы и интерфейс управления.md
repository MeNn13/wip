# Приказы и интерфейс управления

[[ГДД|← Главная страница ГДД]]

> **Статус правил.** Алгоритмы, формулы, коэффициенты и ограничения являются предложениями, кроме явно подтверждённых положений. Перенос документации не означает утверждения решений. Статусы требований и решений — в [[Реестр_требований_и_решений#1 Правила работы с требованиями|реестре]].

**Цель и действия.** Позволить управлять дивизией, армией или группой армий одинаковым способом. Доступны перемещение, оборона, наступление всем фронтом, локальная область наступления, отход, назначение в резерв, остановка. Произвольный полигон цели и шаблоны клина/сектора сохраняют заданную глубину и форму ([[Реестр_требований_и_решений#2 Реестр требований|R20–R24]]).

**Входные данные.** Исполнители, геометрия цели, предельная глубина, агрессивность, целостность, правило растяжения, приоритет снабжения. Настройки наследуются: локальный приказ → армия → группа армий → настройки игрока; значение копируется в приказ при создании. Последующее изменение глобального значения не меняет уже исполняемые приказы без явной команды применения.

**Предложение [[Реестр_требований_и_решений#4 Пакет решений для заказчика|D08]].** Состояния приказа: черновик → принят → подготовка → выполняется → выполнен; дополнительно приостановлен, отменён, невыполним. «Невыполним» означает структурную причину при создании (нет пути, недопустимая цель). «Приостановлен» — временное препятствие исполнения (БК, организация, разрыв). При устранении причины выполняемый план автоматически возобновляется, кроме вынужденного отхода и ручной остановки. Цель автоматически не урезается.

==🟡Порог начала атаки по агрессивности: осторожная `O≥70`, обычная `O≥50`, решительная `O≥30`; везде нужен БК минимум на один полный шаг. По умолчанию обычная агрессивность, сохранение целостности 2 км, максимальное растяжение `w/W=1,25`, резерв без автоматического ввода. Игрок может разрешить до `w/W=2`; превышение блокирует добровольное расширение, но не вынужденное растяжение вследствие отхода соседей. Превышение показывается сразу.==

Наступление всем фронтом задаёт направление нормали к линии на выбранную игроком сторону и глубину ==🟡10 км== по умолчанию; ==🟣предварительный просмотр обязателен.== Локальный полигон должен касаться выбранного участка; единицы распределяются по ширине основания пропорционально `W`. Цель отдельной дивизии — её доступный путь к точке с ограничением глубины. План выполнен, когда бесспорно контролируется вся проходимая целевая область; непроходимые части исключаются из цели при создании и показываются в предпросмотре, скрытая недоступность при обнаружении приостанавливает приказ. Для одиночного движения достаточно прибытия с точностью 100 м.

Редактирование создаёт новую редакцию приказа с тем же ID. Новая команда замещает старую на следующем шаге; при нескольких командах одной части побеждает последняя зарегистрированная. Смена группового приказа не перекрывает отдельный ручной приказ дивизии, пока игрок явно не включит её снова в группу исполнителей. «Стоп» прекращает добровольное движение и атаку, но не огонь противника и не вынужденный отход. ==🟡Из походного режима требуется час развёртывания==.

**Результат и интерфейс.** В черновике видны достижимость, длина, ETA, ожидаемая ширина, потребление и известные риски. У остановленного приказа причина, место, затронутые части и действие: например, «БК исчерпан; ближайшие 20 единиц ожидаются через 5 ч; снизить темп или восстановить мост». Одна причина даёт одно уведомление; повтор — при изменении причины или ухудшении, сводка раз в час. Невыполнимый приказ сохраняется как черновик для исправления, не исчезает.

**Исключения и проверка.** Нельзя атаковать нейтральную сторону через приказ движения. Передача части другому фронту очищает старое назначение. Игрок видит только известную угрозу; прогноз обозначает неопределённость. Параметры: пороги, глубина, наследование, период сводок. Проверки [[Спецификация_прототипа#4 Сценарии приёмки ядра|P01]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P03]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P05]], [[Спецификация_прототипа#4 Сценарии приёмки ядра|P11]].
