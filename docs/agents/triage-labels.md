# Метки triage

| Роль навыка | Метка в GitHub Issues | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется первичная оценка сопровождающим |
| `needs-info` | `needs-info` | Ожидаются дополнительные сведения от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова к автономной работе агента |
| `ready-for-human` | `ready-for-human` | Требуется выполнение человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык называет роль, используй соответствующую метку из таблицы.
При изменении принятого словаря обновляй столбец «Метка в GitHub Issues».
