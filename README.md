# WIP (Рабочее название)

Проект глобальной военной стратегии на Unity. По текущему геймдизайн-документу ядро игры — свободное движение дивизий, непрерывные фронты и физическая доставка грузов к войскам. Игрок определяет цели, распределяет силы и обеспечивает операции на глобальной карте.

Проект находится на начальном этапе: в репозитории есть проект Unity, стартовая сцена и комплект проектной документации. Описанные в ГДД механики задают направление разработки; их наличие в документации не означает, что они уже реализованы.

## Запуск

1. Установите Unity Hub и Unity Editor **6000.6.8f1** — версию из [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
2. Добавьте корневую папку репозитория через **Add project from disk** в Unity Hub.
3. Откройте проект и дождитесь импорта ресурсов и восстановления пакетов. При первом открытии потребуется доступ к реестру пакетов Unity.
4. Откройте сцену `Assets/_Game/Levels/Scenes/SampleScene.unity` и нажмите **Play**.

Проект использует Universal Render Pipeline (URP) и Input System. Зависимости определены в [Packages/manifest.json](Packages/manifest.json).

## Структура

| Путь                     | Назначение                                      |
| ------------------------ | ----------------------------------------------- |
| `Assets/_Game/Art/`      | Графические ресурсы                             |
| `Assets/_Game/Levels/`   | Уровни и сцены. Префабы игры                    |
| `Assets/_Game/Settings/` | Ресурсы настроек игры и рендеринга              |
| `Assets/_Game/_Scripts/` | Каталог для игрового кода                       |
| `Packages/`              | Зависимости Unity                               |
| `ProjectSettings/`       | Настройки проекта Unity                         |
| `docs/ГДД/`              | Геймдизайн, требования и спецификация прототипа |
